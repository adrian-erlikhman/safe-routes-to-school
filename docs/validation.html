Does the risk model predict anything?

Out-of-sample validation for Safe Routes to School. The router is provably correct; that is a different question from whether the thing it routes over is.

Not yet validated against Los Angeles.

The holdout is written, tested and ready, and has never been run on real incidents: the cache is not in the repository and the source API was unreachable from where this was built. No claim about this model’s predictive skill is currently supported. Everything below tests the evaluation, on synthetic fixtures with known answers.

python pipeline/fetch_crime.py
python pipeline/eval/holdout.py

What is actually proven

Three claims, three very different levels of evidence.

A* returns exactly Dijkstra’s costproven
The “safer” route has lower exposurecircular
The risk surface predicts where crime happensuntested

The middle row is true by construction — exposure is defined by the surface — so a surface of random numbers would satisfy it too.

What it cannot tell you

Both the fit and the test come from the same reporting process, with the same variation in who calls the police and who does not. A holdout drawn from one source cannot see past that. Even a passing result would mean the model predicts recorded crime — which is not the same claim, and is not the one a parent reads it as.
